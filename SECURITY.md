# Security policy

## Report a vulnerability

Send suspected security vulnerabilities or security reports to [contact@rondome.dev](mailto:contact@rondome.dev).

Include the affected package version, a description of the issue, steps to reproduce it and its potential impact. A minimal reproduction or proof of concept helps us investigate.

Please report vulnerabilities privately rather than opening a public GitHub issue. Do not include production credentials, API keys or personal data in your report.
